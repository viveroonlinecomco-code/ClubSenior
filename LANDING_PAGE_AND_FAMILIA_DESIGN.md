# 🎨 **DESIGN GUIDELINES**

## Colors
```
Primary:    #10B981 (Green - Health, vitality)
Secondary:  #0D47A1 (Blue - Wisdom, knowledge)
Tertiary:   #8B5A2B (Earth - Heritage, roots)
Accent:     #FFA500 (Orange - Energy, warmth)

Backgrounds:
- Light: #F9FAFB (Gray 50)
- White: #FFFFFF
- Hover: #F3F4F6 (Gray 100)

Text:
- Dark: #111827 (Gray 900)
- Medium: #6B7280 (Gray 600)
- Light: #9CA3AF (Gray 400)
```

## Typography
```
Headings:   Poppins Bold (H1, H2, H3)
Body:       Inter Regular (Body text)
Monospace:  JetBrains Mono (Code)

Sizes:
- H1: 48px (Landing)
- H2: 32px
- H3: 24px
- Body: 16px
- Small: 14px
- Tiny: 12px
```

## Components
```
✓ Cards:     Rounded borders (8px), shadow on hover
✓ Buttons:   Rounded (6px), smooth transitions
✓ Inputs:    Clean, focused state clear
✓ Icons:     Consistent 24px size
✓ Spacing:   Multiples of 8px (8, 16, 24, 32, 48)
```

---

# 📱 **RESPONSIVE DESIGN**

```
Desktop (1200px+):
- Landing: Hero + 4 pilares en grid 2x2 + Testimonios
- Familia: Propósito full width + Actividades + Sidebar reporte

Tablet (768px - 1199px):
- Landing: Responsive grid (1-2 columnas)
- Familia: Propósito + Actividades (1 columna) + Reporte debajo

Mobile (< 768px):
- Landing: Vertical stack, full-width cards
- Familia: Propósito (card) + Actividades (stack) + Reporte (accordion)
```

En ambas páginas, el PROPÓSITO debe ser:

✅ **VISIBLE:** Siempre en el top (landing hero, familia header)
✅ **DESTACADO:** Color llamativo, fuente clara
✅ **MEMORABLE:** Corto, poderoso, resonante
✅ **CONECTIVO:** Relacione con los 4 pilares
✅ **MOTIVADOR:** Inspire a continuar participando
